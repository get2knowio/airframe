# AGENTS.md

Airframe keeps one agent-instruction file. It is
[CLAUDE.md](./CLAUDE.md) — read that.

Two copies of the same instructions is a drift generator, not
redundancy, so this file is deliberately a pointer and nothing else.

Project governance lives in
[.specify/memory/constitution.md](./.specify/memory/constitution.md);
the command surface is `mise run <verb>` (see `mise.toml`), and
`mise run check` is the gate.
